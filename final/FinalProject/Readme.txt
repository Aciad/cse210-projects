Hellow, wecome to this early version of a basic rpg game.
All you need to do to play is run "dotnet build"
One you've done that select option 2 and then you will be in game.
Different tokens mean different things on the screen:
/ is a sword
P is the player
} is a bow
Z is a zombie
S is a skeleton

to use an item pick it up off the ground and hold it. Your 'use' command will use whatever you have in the held slot.
